# Agentes

Entram aqui procedimentos reutilizáveis em qualquer produto nascido deste kit.

Ficam de fora a stack, a definição de produto e as decisões de arquitetura. Elas moram em [`tecnologias.md`](../tecnologias.md), [`produto/`](../produto/) e [`adr/`](../adr/).
