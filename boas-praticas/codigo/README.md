# Código

Práticas de clareza que valem em qualquer stack declarada em [`tecnologias.md`](../../tecnologias.md).

| Arquivo | Assunto |
| --- | --- |
| [`clean-code.md`](clean-code.md) | O que observar no código e o que preferir |
| [`code-smells.md`](code-smells.md) | Sinais de que a estrutura pede mudança, e a mudança preferível |

Entram aqui hábitos de leitura e de desenho do código.

Ficam de fora estilo preso a uma linguagem e ferramentas de análise. A ferramenta entra na seção de restrições ou de testes de [`tecnologias.md`](../../tecnologias.md) quando o produto a adotar, e num ADR quando a adoção precisar de contexto.
