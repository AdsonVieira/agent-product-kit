# Testes

Desenho de testes por [`principios-first.md`](principios-first.md), aplicado em três camadas.

| Arquivo | Camada |
| --- | --- |
| [`unitarios.md`](unitarios.md) | Uma regra ou um comportamento em memória |
| [`integracao.md`](integracao.md) | Uma fronteira entre duas partes |
| [`arquitetura.md`](arquitetura.md) | Uma regra estrutural do repositório |

Entram aqui critérios de desenho dos testes.

Ficam de fora o nome do executor, da biblioteca de duplos e da ferramenta que lê dependências. Essas ferramentas ficam em Ferramentas de teste, em [`tecnologias.md`](../../tecnologias.md). A regra estrutural que um teste de arquitetura protege nasce num ADR.
