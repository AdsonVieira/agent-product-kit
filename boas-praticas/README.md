# Boas práticas

Critérios agnósticos de código, interface, backend e testes. Valem para a stack que [`tecnologias.md`](../tecnologias.md) declarar.

| Pasta | Assunto |
| --- | --- |
| [`codigo/`](codigo/) | Clareza do código e smells a tratar |
| [`frontend/`](frontend/) | Interface, estado e acessibilidade |
| [`backend/`](backend/) | Bordas, validação e direção das dependências |
| [`testes/`](testes/) | FIRST nas camadas unitária, de integração e de arquitetura |

Entram aqui regras que sobrevivem à troca de framework.

Ficam de fora nomes de biblioteca, ferramenta e framework. Essa declaração mora em [`tecnologias.md`](../tecnologias.md). Uma escolha estrutural deste produto mora em [`adr/`](../adr/).
