# Backend

Práticas de borda, validação e dependência, independentes do framework declarado em [`tecnologias.md`](../../tecnologias.md).

O arquivo [`principios.md`](principios.md) descreve o centro do domínio, a validação na entrada, o erro explícito e a direção das dependências.

Entram aqui critérios do comportamento no servidor e do modelo que guarda as regras.

Ficam de fora framework, formato de API e banco. Esses nomes ficam em [`tecnologias.md`](../../tecnologias.md). A regra deste produto fica em [`produto/comportamento.md`](../../produto/comportamento.md) e, quando for estrutural, num ADR.
