# Frontend

Práticas de interface independentes da biblioteca declarada em [`tecnologias.md`](../../tecnologias.md).

O arquivo [`principios.md`](principios.md) cobre limite entre apresentação e coordenação, dono do estado, acessibilidade e os estados vazio, carregando e erro.

Entram aqui critérios da interface que a pessoa usa.

Ficam de fora a biblioteca de interface, o roteamento e o estilo. Esses nomes ficam na seção Frontend de [`tecnologias.md`](../../tecnologias.md). A identidade concreta deste produto fica em [`produto/identidade-visual.md`](../../produto/identidade-visual.md).
