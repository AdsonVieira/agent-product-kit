# Abrir um ADR

Use quando uma tarefa escolher tecnologia, estrutura de módulos, fronteira entre partes ou uma regra que outros arquivos passam a obedecer.

1. Leia [`adr/README.md`](../adr/README.md).
2. Pegue o próximo número de quatro dígitos. O template [`0000`](../adr/0000-template.md) permanece como modelo.
3. Copie o template para `adr/NNNN-titulo-curto.md`.
4. Preencha status, data, contexto, decisão e consequências.
5. Quando a decisão nomear uma ferramenta ou um framework, cite o trecho de [`tecnologias.md`](../tecnologias.md) que a declara.
6. Deixe o status como `proposto` até alguém aceitar. Um ADR aceito que deixa de valer aponta para o ADR que o substitui.
